# FlowState Commander Bolt

An ADHD‑centric planner, habit tracker, and accountability companion with compassionate UX.

Core pillars:
- Tangible time (Visual Time Blocks + Time Confetti)
- Non‑binary habit tracking with compassionate streaks
- Focus‑first interactions (Focus Now mode)
- Built‑in accountability (Body Double)

## Quick Start
1. Open this repo in Cursor IDE
2. Open CURSOR_RUNBOOK.md (the step‑by‑step build guide)
3. Start with Phase 0 and follow the prompts

FlowState Commander Bolt helps reduce time blindness and initiation friction. It emphasizes a calm, Today‑first workflow with gentle nudges and forgiving habit logic.
